# Components Directory

Directory for reusable UI components and presentational logic.

## Organization

- **`/ui`**: Atomic components (buttons, inputs) built on top of HeroUI.
- **`/layout`**: Layout-specific components like `Sidebar`, `Navbar`, and `Footer`.

## Usage

- Use these components to build pages and features.
- Maximize reusability and keep them stateless when possible.
- Follows Atomic Design principles loosely.
