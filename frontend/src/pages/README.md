# Pages Directory

Top-level components representing full application views.

## Contents

- **`Dashboard.tsx`**: Main authenticated landing view.
- **`Landing.tsx`**: Public landing page.
- **`404.tsx`**: Error page for unmatched routes.

## Usage

- Components here should focus on assembling Features and Layouts.
- Minimal logic; delegate business logic to `features` or `hooks`.
- Mapped directly to routes in `src/routes.tsx`.
